# astro-reader

A lightweight PDF reader built with [Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/), designed for embedding PDF documents into documentation sites, digital magazines, and online reading platforms.

It provides a simple way to integrate PDF reading into an Astro-based Starlight website while keeping the reading experience consistent with the surrounding site.

To see how to get started, check out the [package README](./packages/astro-reader/README.md)
